# PixelForge Distribution Plan

## 1. Product Hunt Launch (highest leverage)

### Tagline
Free AI Image Tools — Remove Backgrounds, Upscale 4x, Restore Photos. No Signup.

### Description
PixelForge is a collection of 6 free AI-powered image tools that work directly in your browser. No signup, no credit card, no waiting.

🔧 What you can do:
• Remove backgrounds from any image instantly
• Upscale images up to 4x with AI super-resolution
• Restore old, damaged photos to HD quality
• Compress images without visible quality loss
• Convert between PNG, JPEG, and WebP formats
• Crop images to any aspect ratio

🏆 Why PixelForge?
• 100% free — all tools, unlimited for free tier
• Privacy-first — some tools run entirely in your browser
• Instant results — no queue, no waiting
• Clean, fast UI — no clutter, no ads

💰 Pro plan: $9.99/month for unlimited usage + HD quality

🔗 https://pixel-forge-jain.vercel.app

I built a collection of 6 AI image tools that work in the browser with no signup. 

The AI tools (background removal, upscaling, photo restoration) use Replicate's API. The free tools (compression, format conversion, cropping) run entirely client-side.

Free tier: 3 uses/tool/day. Pro: $9.99/month unlimited.

Built with Next.js, Replicate, and LemonSqueezy. Entire source is ~3,000 lines of TypeScript.
